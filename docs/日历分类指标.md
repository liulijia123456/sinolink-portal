# 大事日历 · 分类指标说明

> 适用对象：`index.html` 中 `id="us-cal-data"` 的 `events` 数组（当前 251 条，2026-10-31）。
> 配套文件：《日历条目清单.md》《日历条目清单.csv》；执行脚本 `scripts/cal_classify.py`。

## 1. 为什么重做分类

原方案只有 `econ / pol / dip / hol` 四类，两个结构性问题：

1. **「经济」是个筐**。169 条 `econ` 里混着 8 条行政机关的规则制定——SEC 加密资产规则、
   EPA 三氯乙烯合规延期、财政部对外投资安全计划、OCC 稳定币规则等。这些条目不发布
   任何统计数据，产出的是**有约束力的规则**。
2. **「政治」被饿死**。四类里 `pol` 只有 12 条（选举与国会程序），而拨款、关税措施、
   监管规则这些政府行为散落在 `econ` 与 `dip`，导致「政治」在图例上几乎不出现，
   读者也无从按政治线索筛选。

重做后：`econ 154 · pol 20 · dip 22 · mkt 55`。政治类从 12 条增到 20 条；
「经济」仍是统计发布与货币政策的大类，但不再是政策行为的收容所。

## 2. 三个指标

三个指标互相正交：`cat` 决定**视觉分类**（色条与图例），`topic` 决定**主题检索**，
`actor` 决定**责任归属**。

| 指标 | 含义 | 取值数 | 适用条目范围 |
| --- | --- | --- | --- |
| `cat` | 一级范畴 | 4 | 全部条目，必填 |
| `topic` | 议题域 | 11 | 全部条目，必填 |
| `actor` | 主导主体 | 8 | 全部条目；`mkt` 类统一填 `none` |

### 2.1 `cat` 一级范畴

判定顺序固定为 **mkt → econ → dip → pol**，命中即止，避免边界摇摆。

| 值 | 名称 | 定义 | 纳入 | 排除 |
| --- | --- | --- | --- | --- |
| `econ` | 经济 | 官方统计机构按**预排日程**发布的指标数据，以及美联储的货币政策决议 | CPI、PPI、PCE、GDP、非农、零售销售、零售电商、贸易差额、进出口价格、ECI、ECEC、国际收支；FOMC 议息会议与纪要 | 规则生效（→`pol`）；美联储的**监管**规则（→`pol`，`actor=fed`） |
| `pol` | 政治与治理 | 政府、立法、司法机关的决定与程序，以及行政机关的规则制定 | 选举与就职、国会程序、拨款与停摆节点、监管规则的意见期与生效、关税与贸易救济等**美方单边措施**、司法裁判 | 纯统计数据与议息（→`econ`）；双边或多边磋商节点（→`dip`） |
| `dip` | 外交与安全 | 多边机制会议、双边磋商节点，以及须写明传导路径的外国政治事件 | G20、APEC、Quad、东盟、IMF-世行、COP、达沃斯、慕安会、中美关税休战、以色列大选 | 美国国内程序（→`pol`） |
| `mkt` | 交易日历 | 决定交易所开市与否、交易时长与联邦雇员休假的固定节点 | 联邦假日、NYSE/Nasdaq 全天休市与提前收市、夏令时/冬令时切换 | 与休假和交易无关的纪念日 |

三条容易混淆的边界，按此判：

1. **议息 ≠ 监管**。FOMC 决议改的是政策利率（`econ`，`topic=money`）；美联储的压力测试
   透明度新规、资本计划规则修订改的是机构行为规范（`pol`，`actor` 仍记 `fed`）。
2. **美方单边 vs 双边磋商**。301 条款关税暂停、USMCA 联合审查属美方贸易政策程序（`pol`）；
   中美关税休战延期届满是对等磋商的时间节点（`dip`）。
3. **外国选举归外交**。以色列议会选举进 `dip`，因为收它的理由是「与美国对伊政策联动」，
   须在备注写明传导路径；美国自身的选举进 `pol`。

### 2.2 `topic` 议题域

| 值 | 名称 | 覆盖内容 |
| --- | --- | --- |
| `price` | 物价 | CPI、PPI、PCE |
| `labor` | 就业与薪酬 | 非农就业报告、ECI、ECEC |
| `growth` | 增长与消费 | GDP、零售销售、零售电商、国际交易与对外投资头寸 |
| `trade` | 贸易与外部平衡 | 贸易差额、进出口价格、APEC、关税休战、USMCA、301 关税 |
| `money` | 货币与金融监管 | FOMC、IMF-世行、G20（财长/峰会/Sherpa）、达沃斯、银行资本与稳定币规则、加密资产 |
| `fiscal` | 财政与住房 | 联邦政府拨款截止、住房法相关规则 |
| `tech` | 科技与投资安全 | 对外投资安全计划（COINS 法案）等投资审查规则 |
| `energy` | 能源与环境 | EPA 规则、COP |
| `security` | 安全与地缘 | Quad、慕安会、东盟、G20 外长会 |
| `election` | 选举与政治程序 | 美国与外国的选举、就职、国会开幕、计票 |
| `calendar` | 假期与时制 | 联邦假日、时制切换 |

议题按**机制的主要议程**定，不按举办方定：G20 领导人峰会与财长会记 `money`，G20 外长会记
`security`；IMF/世行年会虽属外交场合，议程是宏观金融，也记 `money`。

### 2.3 `actor` 主导主体

| 值 | 名称 | 判定 |
| --- | --- | --- |
| `stats` | 统计机构 | BLS、BEA、普查局（含联合发布） |
| `fed` | 美联储 | FOMC 与美联储自身的规则 |
| `agency` | 独立监管机构 | SEC、EPA、OCC 等 |
| `exec` | 行政部门 | 白宫、财政部、USTR、国务院、商务部；选举类条目（选举日、证书递交、选举人会议、就职）因属法定程序，其执行方为行政部门与州选举机构，一并记此值 |
| `congress` | 国会 | 拨款、国会开幕、联席会议计票 |
| `court` | 司法 | 法院裁判（当前无此类条目） |
| `intl` | 外国或多边 | 多边机制秘书处、外国政府 |
| `none` | 不适用 | `mkt` 类：假日由成文法与交易所规则决定，无单一政策主体 |

`actor` 回答「谁做出的决定」，不是「谁报道的」。统计发布一律 `stats`，即便数据由 BEA 与
普查局联合发布也不拆分。

## 3. 口径规范（与指标配套）

### 3.1 字段写法

| 字段 | 规范 |
| --- | --- |
| `title` | 「事件名（属性）」；假日统一「节日名（联邦假日）」或「节日名（联邦假日，美股休市）」 |
| `s` | 格内短标签，2—7 字，视觉宽度 ≤66px（汉字 10.5px / ASCII 5.5px 计），不带月份 |
| `note` | 「地点 · 说明 · 来源：机构全称（缩写）」；段间用 ` · `；只保留一个「来源：」并置于末尾；不以句号结尾 |
| `note` 禁忌 | 不写时刻（展开行已显示 `时刻` 字段）、不写与 `d2` 相同的会期 |

### 3.2 假日条目专项规范

1. 标题后缀由 **NYSE 假日族规则**判定，不采信原标题写法。哥伦布日、退伍军人节美股照常
   交易，后缀只写「（联邦假日）」。
2. 例外固定为一条：`2027-12-31` 是 2028 年元旦的联邦观察日，**纽交所当日照常交易**，
   标题保留「2028 年元旦（联邦假日）」，不带休市后缀。
3. 备注统一为「休市状态 + 个别说明 + 来源」：
   `美股休市 · 次日 11 月 27 日（周五）13:00 提前收市 · 来源：NYSE 2026—2028 交易日历`。
4. 「华盛顿诞辰日」并入「总统日」后，备注补回法定名称
   `法定名称为华盛顿诞辰日（Washington's Birthday）`，事实不随标题归并而丢失。
5. 星期统一写「周」（周一/周二…），不混用「星期一」。

### 3.3 来源写法

机构一律「全称（缩写）」：美国劳工统计局（BLS）、美国经济分析局（BEA）、美国普查局（Census）、
美国联邦储备委员会（Federal Reserve）、美国人事管理局（OPM）。法条写 `§ 数字` 带空格。
若原文括注已写明来源（如「（路透社 / 菲总统府公告）」），以括注为准，不另套机构名——
那等于虚构出处。

## 4. 与日更任务的接口

`scripts/cal_classify.py` 是这套指标的唯一执行入口：

```bash
python3 scripts/cal_classify.py check       # 体检：覆盖、取值合法性、数据与规则是否一致
python3 scripts/cal_classify.py report      # 按范畴打印，或 --csv 导出
python3 scripts/cal_classify.py apply       # 写入三个指标（幂等）
python3 scripts/cal_classify.py apply --fix-holiday   # 同时统一假日标题与备注
```

新条目入库后，日更任务执行 `apply` 即可补齐指标；若规则判错，在 `OVERRIDES` 里按
`(日期, 标题)` 加一条覆盖，并在提交信息里写明理由。`check` 退出码非 0 即表示
「有条目无法归类」或「数据与规则不一致」，需先修再提交。

## 5. 已知局限

- `topic` 对多议程会议只能取主轴：G20 领导人峰会议程同时覆盖贸易与安全，按经济议程记
  `money`，其安全侧面需靠备注体现。
- 外国政治事件仅收录与美国有直接传导者，`dip` 的边界因此取决于备注里是否写清传导路径，
  这一条目前靠人工把关，未做机器校验。
- 「经济」合并了统计发布与货币政策：两者在议程上都是市场定价的直接输入，但性质不同
  （前者是信息、后者是决策）。若日后需要区分，可按 `topic=money` 与 `actor=fed` 把 FOMC
  单独筛出，无需改 `cat`。
